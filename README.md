Тестовый проект, мини-СУБД по учёту технических средств ТКДРМ.
Разрабатывается в свободное от основной работы время.
В открытом доступе залитой БД нет. Есть только её структура, описание моделей и рисунок схемы (ниже). На данный момент разработка идет с использованием около 9000 валидированных записей таблицы Device, при планируемом в проде их количестве до 20000.

Бекенд-технологии: Python, Django, DRF, SQLite (перспектива - PostgreSQL).

Фронтенд: React вайбкодинг Google Gemini.

Для запуска проекта:
- git clone репозиторий.
- Создать venv. Установить в него зависимости.
- cd tkdrm1
- Сделать одно из:
    - Опция1:
        - python manage.py makemigrations
        - python manage.py migrate
        - Обеспечить в общей папке с manage.py наличие двух легаси-Excel-файлов для импорта данных из них
        - python manage.py import3
        - ждать 15...60 минут
        - python manage.py import4
        - ждать 6..20 минут
    - Опция2:
        - получить от разработчика файл БД db.sqlite3 и положить его рядом с manage.py
- python manage.py runserver
- Обеспечить установленное Node.js
- cd my-frontend
- npm start

После запуска проекта будет доступно:
-  http://127.0.0.1:8000/admin/
-  По REST API, в клиенте:
    -  GET http://127.0.0.1:8000/all_list/by_cpl5/
    -  GET http://127.0.0.1:8000/all_list/by_cpl5/ID/
    -  POST http://127.0.0.1:8000/all_list/by_cpl5/
    -  PUT http://127.0.0.1:8000/all_list/by_cpl5/ID/
    -  PATCH http://127.0.0.1:8000/all_list/by_cpl5/ID/
    -  DELETE http://127.0.0.1:8000/all_list/by_cpl5/ID/
