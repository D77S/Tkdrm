Тестовый проект, мини-СУБД по администрированию технических средств т.контроля.
Разрабатывается в свободное от основной работы время.

Технологии: Python, Django, MySQL (перспектива - PostgreSQL)

Done:
- структура БД, наиболее точно отражающая реальное положение дел. На настоящее время около 20 таблиц.
- management-команда, парсер легаси БД из Excel, готово на 90%
- две первые view-функции, общие перечень объектов и детализация одного объекта.
- пагинация, кастомная, самописная.
