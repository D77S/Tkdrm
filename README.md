Тестовый проект, мини-СУБД по учёту технических средств ТКДРМ.
Разрабатывается в свободное от основной работы время.
На настоящее время разработка идёт с частичным наполнением БД. В открытом доступе залитой БД нет. Есть только её структура, описание моделей и рисунок схемы (ниже). У разработчика на данный момент есть около 1500 валидированных записей таблицы Device, при планируемом в проде их количестве около 20000.

Технологии: Python, Django, MySQL (перспектива - PostgreSQL)

Done:
- структура БД, всё более и более точно описывающая реальные сущности. На настоящее время более 30 таблиц.
- management-команда, парсер легаси БД из Excel, только по СТСО.
- две первые view-функции, общие перечень объектов и детализация одного объекта.
- пагинация, кастомная, самописная.
